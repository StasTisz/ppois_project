# Movie Recommendation Telegram Bot (C++)

Проект курсовой работы по дисциплине **ППОИС** (Программирование на принципах объектно-ориентированных систем).  
Телеграм-бот для персонализированной рекомендации фильмов, написанный на **C++20**.

---

## 🚀 Стек технологий
- **Язык**: C++20
- **Среда разработки / Компилятор**: Visual Studio (MSVC)
- **Система сборки**: CMake (`CMakePresets.json`)
- **Менеджер пакетов**: vcpkg (в режиме манифеста `vcpkg.json`)
- **Библиотеки**: `tgbot-cpp`, `sqlite3`, `nlohmann/json`, `Google Test (gtest)`

## 👥 Распределение задач

### 🔹 Миша: Ядро, база данных и алгоритмы рекомендаций (Backend & Data)

Зона ответственности: всё, что касается хранения данных, математики рекомендаций и бизнес-логики.

* **Задача 1.1: Слой хранения и база данных SQLite** [x]
  * Создание таблиц (`movies`, `users`, `ratings`, `favorite_genres`).
  * Подготовка начального датасета (скрипт `data/seed_movies.sql` и JSON `data/initial_movies.json` с 60 популярными фильмами).
* **Задача 1.2: Слой репозиториев (Repository Pattern)** [x]
  * Реализация `SQLiteMovieRepository` (поиск по ID, выборка по жанрам, топ по рейтингу, добавление, подсчет).
  * Реализация `SQLiteUserRepository` (сохранение пользователя, истории просмотров, выставленных оценок, любимых жанров).
* **Задача 1.3: Базовый движок рекомендаций (Strategy Pattern)** [x]
  * Реализация интерфейса `IRecommendationStrategy`.
  * Стратегия 1: **Cold-Start / Popularity** (`PopularityRecommendationStrategy` — подбор топовых фильмов по выбранным любимым жанрам для новых пользователей с автофильтрацией просмотренных).
* **Задача 1.4: Продвинутая рекомендация (Content-Based Filtering)** [x]
  * Стратегия 2: **Content-Based** (`ContentBasedRecommendationStrategy` — вычисление сходства по жанрам через метрику Жаккара, совпадению режиссера и эпохи с весами пользовательских оценок).
  * Логика исключения: фильтрация уже просмотренных и оценённых фильмов.
* **Задача 1.5: Сервис-фасад `RecommendationService`** [x]
  * Объединение стратегий в единый фасад (паттерн **Facade**), автоматический выбор стратегии (Auto / Popularity / ContentBased) в зависимости от истории пользователя.
  * Дополнительные методы: поиск похожих фильмов (`getSimilarMovies`), валидация и сохранение оценок (`rateMovie`), работа с любимыми жанрами.
* **Задача 1.6: Unit-тесты (Google Test)** [x]
  * Комплексное модульное и интеграционное тестирование (`tests/`):
    * `test_repository.cpp` — CRUD-операции, обработка кавычек и спецсимволов (SQL-инъекции), пустая БД, каскадное удаление внешних ключей, сидирование датасета.
    * `test_recommendation.cpp` — проверка алгоритмов популярности и контентной фильтрации (Жаккар, веса оценок, тайбрейки, фильтрация просмотренного).
    * `test_service.cpp` — тестирование фасада `RecommendationService`, авто-переключения стратегий, валидации оценок и похожих фильмов.
    * `test_pipeline.cpp` — сквозной тест жизненного цикла пользователя на реальном датасете из 60 фильмов.

### 🔹 Стас: Telegram-бот, конечный автомат и интерфейс (Bot & UI)

Зона ответственности: всё взаимодействие с Telegram API, сценарии диалога, кнопки и отображение.

* **Задача 2.1: Инициализация бота и инфраструктура событий** [x]
  * Запуск long-polling цикла через `tgbot-cpp`.
  * Базовая обработка входящих текстовых сообщений и callback-запросов (кликов по кнопкам).
* **Задача 2.2: Конечный автомат диалогов (State / FSM Pattern)** [x]
  * Реализация состояний пользователя:
    * `DefaultState` (главное меню);
    * `GenreSelectionState` (выбор любимых жанров при старте);
    * `BrowsingRecommendationsState` (просмотр фильма и ожидание реакции);
    * `RatingState` (выставление оценки фильму).
* **Задача 2.3: Фабрика интерфейса (Keyboard / View Factory)** [x]
  * Генерация Inline-клавиатур:
    * Мультивыбор жанров (с галочками);
    * Кнопки реакций под фильмом: `👍 Понравился`, `👎 Не понравился`, `⏭ Следующий`, `⭐ Оценить (1-10)`;
    * Кнопки главного меню.
* **Задача 2.4: Маршрутизатор команд (Command Dispatcher)** [x]
  * Обработка команд: `/start` (онбординг), `/recommend` (запуск подбора), `/genres` (смена предпочтений), `/history` (просмотренное), `/help`.
* **Задача 2.5: Оформление карточки фильма** [x]
  * Форматирование сообщения: отправка постера, названия, года, жанров, рейтинга и синопсиса.
  * Корректная обработка сетевых ошибок Telegram API и таймаутов.
* **Задача 2.6: Интеграция с ядром (подключение к `RecommendationService`)** [x]
  * Вызов методов сервисов Разработчика 1 при нажатиях кнопок пользователем и передача результатов в чат.

## 🛠️ Инструкция по сборке в Visual Studio

1. **Клонировать репозиторий**:
   ```bash
   git clone https://github.com/StasTisz/ppois_project.git
   ```
2. **Открыть в Visual Studio**:
   * Запустите Visual Studio.
   * Выберите **«Открыть локальную папку» (Open Folder)** и укажите папку `ppois_project`.
   * Visual Studio автоматически обнаружит `vcpkg.json` и `CMakeLists.txt`.
   * Встроенный vcpkg автоматически восстановит зависимости (`tgbot-cpp`, `sqlite3`, `nlohmann-json`, `gtest`).
3. **Сборка и запуск**:
   * В верхнем меню выберите конфигурацию `x64-Debug`.
   * Выберите цель сборки `movie_rec_bot.exe` и нажмите **F5** (Запуск с отладкой) или **Ctrl+F5**.
   * Запуск тестов: меню `Тест` -> `Обозреватель тестов` (Test Explorer).
